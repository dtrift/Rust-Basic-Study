# Дизайн: домашние задания по курсу «Rust Basic»

Утверждённый дизайн системы домашних заданий для подростка 13–14 лет.
Курс: 42 урока, из них 5 Q&A-сессий без ДЗ (11, 20, 29, 36, 42). Итого 37 заданий.

## A. Игра

Одна консольная текстовая RPG, растущая с каждым уроком: от карточки героя (урок 3)
до полноценной игры с картой, боями, инвентарём, фоновым миром и релизом v1.0 (урок 41).

- Сеттинг и название подросток выбирает сам в ДЗ-1; все задания пишутся нейтрально
  («герой», «комната», «существо», «предмет») и от сеттинга не зависят.
- Каждое ДЗ: 1–2 часа, 2–5 подзадач, последняя часто со звёздочкой (необязательно).
- Внешние зависимости — только `rand` (ДЗ-06) и `tokio` (ДЗ-40), подключаются через
  `cargo add` в своих уроках.

## B. Репозиторий и процесс

- `main` всегда собирается и проходит CI.
- Цикл: обновить `main` → ветка `hw-NN-slug` → маленькие коммиты → push → PR по шаблону →
  ревью наставника → правки в той же ветке → merge → ветка удалена.
- CI (GitHub Actions) на каждый PR и push в main: `cargo build`, `cargo test`, `cargo fmt --check`.
- Зелёный чек CI — часть определения «сделано».

Структура:

```
├── .github/workflows/ci.yml
├── .github/PULL_REQUEST_TEMPLATE.md
├── docs/
│   ├── homework/          # 37 файлов заданий + README-индекс
│   ├── git-guide.md       # памятка подростку
│   └── mentor-guide.md    # инструкция наставнику
├── src/main.rs            # стартовый hello-world (CI зелёный с первого дня)
├── Cargo.toml
├── .gitignore
└── README.md
```

## C. Формат файла задания

Заголовок (номер, тема урока, имя ветки, время) → Цель → Легенда → Задачи (чек-лист,
последний пункт часто со звёздочкой) → Самопроверка (команды и ожидаемое поведение) →
Подсказки (наводки без готовых решений).

## D. Роли

- Подросток: сдаёт ДЗ через PR, читает docs/git-guide.md.
- Наставник: ревьюит по docs/mentor-guide.md (сначала похвалить, максимум 3 замечания,
  не коммитить за подростка).

## E. Верификация заготовки

- Номера уроков и имена веток согласованы между всеми файлами.
- CI-yaml и Cargo.toml валидны, CI зелёный на старте (hello-world уже в репозитории).
- Каждое задание использует только материал пройденных уроков.
