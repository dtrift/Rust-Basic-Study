# ДЗ 40. Асинхронность. Event Loop, async/await, tokio

- **Урок:** 40. Асинхронность. Понятие Event Loop, проблема 10k соединений. Использование async await
- **Ветка:** `hw-40-async`
- **Время:** примерно 2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-40-async`.

## Цель

Выйти в асинхронный мир: подключить tokio, запустить фоновую async-задачу «болтовни
подземелья», обмениваться данными с игровым циклом по каналу. Понять, чем задача
(task) отличается от потока (thread).

## Легенда

Мир из ДЗ-31–32 жил в отдельном потоке — а теперь переезжает в асинхронный рантайм:
тысячи «событий» могут жить на одном потоке. Подземелье обрастает слухами, слухи
прилетают по каналу, а звёздный пример — сервер табло рекордов, к которому можно
подключиться вторым терминалом.

## Задачи

- [ ] Подключи tokio: `cargo add tokio --features full`.
- [ ] Собери рантайм и канал в `main`:

  ```rust
  let rt = tokio::runtime::Runtime::new().unwrap();
  let (tx, mut rx) = tokio::sync::mpsc::channel::<String>(16);
  rt.spawn(gossip(tx));
  ```

  Игровой цикл остаётся обычным кодом (в рантайм не переезжает).

- [ ] Напиши async-задачу `async fn gossip(tx: tokio::sync::mpsc::Sender<String>)`:
      бесконечный цикл, раз в 2–4 секунды (случайно) отправляет слух подземелья в канал
      (`tx.send(...).await`), между сообщениями `tokio::time::sleep(...).await`.
- [ ] Приём в игровом цикле без блокировки: перед каждым ходом
      `while let Ok(msg) = rx.try_recv() { println!("🌍 {msg}"); }`.
- [ ] Остановка: атомарный флаг уже есть из ДЗ-31 — при выходе дропай `tx`/останавливай
      задачу (пусть gossip проверяет флаг через `tokio::sync::watch` или просто
      завершайся, когда канал закрылся: `tx.send` вернул ошибку).
- [ ] Ответь в комментарии в `main.rs`: чем async-задача отличается от потока?
      Сколько потоков у твоей gossip-задачи? (Подсказка: `rt.spawn` не создаёт
      поток на каждую задачу.)
- [ ] * Звёздочка: TCP-сервер табло. `tokio::net::TcpListener` на `127.0.0.1:7777`
      в задаче рантайма: по подключению (можно `nc 127.0.0.1 7777` из второго
      терминала) отправляй топ искателей из ДЗ-34 или статистику героя, закрывай
      соединение. Игрок может похвастаться друзьями!

## Самопроверка

- Слухи прилетают в игровом цикле с префиксом «🌍», ввод игрока не блокируется.
- Выход из игры завершает программу чисто (без зависших задач).
- Комментарий про task-vs-thread на месте.

## Подсказки

- `try_recv()` — «заглянуть без ожидания»: если пусто, идём дальше. Обычный `recv().await`
  блокировал бы ход игрока.
- Канал tokio живёт в рантайме, а твой игровой цикл — снаружи: их связывает `try_recv`.
- Звёздочка: `listener.accept().await` в цикле; ответ — `socket.write_all(...).await`.
