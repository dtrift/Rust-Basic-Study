# ДЗ 16. Введение в лямбда-функции

- **Урок:** 16. Введение в лямбда-функции (замыкания)
- **Ветка:** `hw-16-closures`
- **Время:** примерно 1–1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-16-closures`.

## Цель

Освоить замыкания: маленькие функции без имени, которые «запоминают» окружение.
Сортировки, фильтры и правила подсчёта в Rust почти всегда пишутся замыканиями.

## Легенда

Торговец в деревне предлагает герою разложить сумку по-разному: по алфавиту,
от лёгкого к тяжёлому, от тяжёлого к лёгкому. Писать три функции сортировки — скучно.
Одна сортировка и три замыкания-правила — по-растовски.

## Задачи

- [ ] Отсортируй сумку по алфавиту: `hero.inventory.sort_by(|a, b| a.name.cmp(&b.name));`
      — разбери, что здесь замыкание и что оно сравнивает.
- [ ] Отсортируй по возрастанию веса: замыкание сравнивает `a.weight` и `b.weight`.
      Потом по убыванию — просто поменяй `a` и `b` местами. Напечатай оба варианта.
- [ ] Заведи переменную-замыкание `let damage_rule = |level: u32| level * 2 + 5;`
      и используй её в бою вместо формулы. Проверь: `damage_rule(3) == 11`.
- [ ] Замыкание с захватом: `let threshold = 10; let is_heavy = |item: &Item| item.weight > threshold;`
      — замыкание «видит» переменную снаружи. Отфильтруй и напечатай только тяжёлые предметы
      обычным циклом с `if is_heavy(item)`.
- [ ] Эксперимент с захватом: сделай замыкание, которое увеличивает счётчик находок
      `let mut finds = 0; let mut count_find = || finds += 1;` — вызови три раза,
      потом напечатай `finds` (подсказка: печатать придётся до или после — попробуй
      оба варианта и объясни в комментарии, почему один не компилируется).
- [ ] * Звёздочка: замыкание-описатель `let label = |hero: &Hero| format!("{} ({})", hero.name, hero.level);`
      и используй его при печати карточки героя.

## Самопроверка

- Сумка печатается в трёх порядках: по алфавиту, по весу вверх, по весу вниз.
- Формула урона живёт в замыкании и используется в бою.
- В комментарии объяснено, когда захват мешает компиляции (E0502/E0387).

## Подсказки

- Синтаксис: `|параметры| выражение` — типы часто можно не писать, Rust угадает.
- `sort_by` ожидает правило «меньше, равно, больше» — как функция сравнения.
- Замыкание, меняющее внешние данные, обязано объявляться `let mut` и захватывать по `&mut`.
