# ДЗ 05. Ветвление и циклы

- **Урок:** 5. Ветвление и циклы
- **Ветка:** `hw-05-branches-loops`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-05-branches-loops`.

## Цель

Сделать первый интерактивный игровой цикл: игра спрашивает игрока, что делать,
и реагирует на выбор. Это первый момент, когда в игру можно «играть».

## Легенда

До сих пор игра только рассказывала про героя. Сегодня герой попадает в тёмную комнату,
и дальше всё зависит от игрока: осмотреться, пойти или сразиться с тем, кто там прячется.

## Задачи

- [ ] Скопируй в конец `main.rs` готовую функцию чтения ввода (она ниже). Разберёшь её позже —
      пока просто пользуйся:

  ```rust
  use std::io::{self, BufRead, Write};

  fn read_input(prompt: &str) -> String {
      print!("{prompt}");
      io::stdout().flush().unwrap();
      let mut line = String::new();
      io::stdin().lock().read_line(&mut line).unwrap();
      line.trim().to_lowercase()
  }
  ```

- [ ] Сделай игровой цикл: печатай номер хода и вопрос «Что делаешь? (осмотреться / бить / бежать / выход)»,
      читай ответ через `read_input` и обрабатывай его в `match`:
  - «осмотреться» — печатаешь описание комнаты (пока просто текст);
  - «бить» — печатаешь «Ты бьёшь воздух: здесь пока никого»;
  - «бежать» — печатаешь «Ты в панике бежишь к выходу» и выходишь из цикла;
  - «выход» — прощаешься и выходишь из цикла;
  - что-то другое — «Не понимаю: ...».
- [ ] Посчитай ходы: переменная-счётчик, увеличивается каждую итерацию.
- [ ] Добавь событие: на 3-м ходу в комнате появляется гоблин (счётчик достиг 3). Теперь:
  - «бить» — один обмен ударами: у героя и гоблина есть hp, урон пока константы;
    печатай, кто сколько получил; если чьё-то hp дошло до 0 — печатай итог боя;
  - «бежать» — при живом гоблине побег получается только со второй попытки
    (первая — «гоблин преграждает путь!»).
- [ ] * Звёздочка: после победы над гоблином герой находит золото, и оно прибавляется
      к `hero.gold` — покажи новый баланс.

## Самопроверка

- Игра запускается, спрашивает «Что делаешь?», реагирует на все 4 команды.
- На 3-м ходу появляется гоблин, бой работает, у hp обеих сторон они уменьшаются.
- «выход» и победа/поражение заканчивают цикл — программа не зацикливается.
- Повторный запуск ведёт себя одинаково (гоблин всегда на 3-м ходу).

## Подсказки

- `loop` + `break` удобнее `while`, когда условие выхода внутри тела.
- `match choice.as_str() { "осмотреться" => ..., "бить" => ..., _ => ... }`.
- Заведи `goblin_hp` переменной рядом со счётчиком хода.
- Урон пока без случайности — константы. Честный рандом подключим в следующем ДЗ.
