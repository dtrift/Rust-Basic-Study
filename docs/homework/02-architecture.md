# ДЗ 02. Основы архитектуры компьютера

- **Урок:** 2. Основы архитектуры компьютера
- **Ветка:** `hw-02-architecture`
- **Время:** примерно 1 час

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-02-architecture`.

## Цель

Почувствовать границы чисел в компьютере: переполнение, точность дробей, размер типов.
Научиться выбирать тип для характеристик героя осознанно, а не «наугад».

## Легенда

У героя будут характеристики: здоровье, уровень, золото, координаты. Компьютер хранит
числа с ограничениями — если выбрать тип не подумав, герой внезапно «умрёт» на 256
единицах здоровья или потеряет копейки из-за округления. Проверим границы на практике.

## Задачи

- [ ] Эксперимент 1 — переполнение: создай `u8` со значением 255, прибавь 1 и напечатай.
      Сначала в обычном `cargo run` (это debug-сборка), потом в `cargo run --release`.
      Запиши, чем поведение отличается и почему.
- [ ] Эксперимент 2 — точность: посчитай и напечатай `0.1 + 0.2` в `f32` и в `f64`,
      сравни с `0.3`. Запиши вывод.
- [ ] Эксперимент 3 — размер: с помощью `std::mem::size_of` напечатай размеры
      `u8`, `u32`, `i64`, `f32`, `bool` и кортежа `(u8, u32)`.
- [ ] Ответь письменно в файле `docs/answers/02-architecture.md` (создай папку и файл):
      1. Почему для здоровья героя лучше `u32`, а не `u8`?
      2. Почему для золота лучше целый тип, а не `f32`?
      3. Что такое переполнение и почему в debug-сборке оно паникует, а в release — «заворачивается»?
- [ ] * Звёздочка: проверь, что будет, если из `0u8` вычесть 1 в debug и release. Запиши ответ.

## Самопроверка

- `cargo run` печатает результаты всех трёх экспериментов с подписями (что печатаем).
- `cargo run --release` ведёт себя иначе в эксперименте 1 — и ты можешь объяснить почему.
- Файл `docs/answers/02-architecture.md` существует, на все 3 вопроса даны ответы своими словами.

## Подсказки

- `let x: u8 = 255; let y = x + 1;` — если компилятор не даёт, попробуй `x + 1` в `println!`
  или `u8::MAX`.
- «Заворачивание» — по-английски wrapping: 255 + 1 превращается в 0, как одометр в машине.
- Экспериментальный код пиши прямо в `main()` — в следующем ДЗ мы его перепишем, это нормально.
