# ДЗ 38. Продвинутые элементы синтаксиса

- **Урок:** 38. Продвинутые элементы синтаксиса
- **Ветка:** `hw-38-advanced-syntax`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-38-advanced-syntax`.

## Цель

Прокачать pattern matching до взрослого уровня: деструктуризация структур и кортежей
прямо в match, охранные выражения (match guards), и написать трейт с ассоциированным
типом.

## Легенда

Команды игры несут данные: `Take("меч")`, `Go(North)`, `Use(3)`. До сих пор доставали
внутренности по одному. Сегодня — разбор одним движением, как опытные: образец
`Command::Take(item) if hero.bag.is_full()` говорит сам за себя. А заодно у эффектов
предметов появятся разные типы результатов — и с этим справится associated type.

## Задачи

- [ ] Деструктуризация в match: минимум 3 образца с распаковкой данных, например
      `Command::Go(dir) => ...`, `Command::Take(name) => ...`, `RoomEvent::Trap { damage } => ...`.
      И кортежный образец где-нибудь: `match hero.position { (0, 0) => "старт", (x, 0) => ... }`.
- [ ] Match guards: минимум 2 охранных образца:
      `Command::Go(_) if hero.stamina == 0 => "Слишком устал"`,
      `Command::Take(_) if hero.bag.is_full() => "Сумка полна"`.
- [ ] Ignoring и range: образец с `..`-rest или `_` для ненужных полей:
      `Item { name, .. } => ...`. Объясни в комментарии, зачем иногда выгоднее
      перечислить все поля.
- [ ] Проверка исчерпываемости на своей шкуре: добавь в `Command` новый вариант
      `Command::Sleep` и собери проект. Компилятор перечислит ВСЕ match, которые
      надо дополнить — ни один не забыт. Допиши обработку везде. Это супер-сила
      enum + match: в комментарии объясни, почему `_`-заглушка съедает эту защиту.
- [ ] Ассоциированный тип: `trait Effect { type Outcome; fn apply(&self, hero: &mut Hero) -> Self::Outcome; }`
      и две реализации: аптечка (Outcome = u32, сколько вылечено) и бомба
      (Outcome = Vec<String>, список задетых существ).
- [ ] * Звёздочка: nested-деструктуризация в образце: `Some(Item { name, .. })` внутри
      `if let` при поиске предмета.

## Самопроверка

- В коде минимум 3 деструктурирующих и 2 охранных образца — наставник их найдёт.
- `Command::Sleep` обрабатывается во всех match без `_`-заглушек.
- Две реализации `Effect` с разными `Outcome` компилируются и работают.

## Подсказки

- Guard пишется после образца: `Pattern if условие => ...`.
- `..` в образце структуры — «остальные поля не интересуют».
- Ассоциированный type выбирается реализацией, а не пользователем трейта —
  в отличие от генерик-параметра.
