# ДЗ 35. Interior mutability

- **Урок:** 35. Interior mutability
- **Ветка:** `hw-35-interior-mutability`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-35-interior-mutability`.

## Цель

Понять `Cell` и `RefCell`: изменяемость внутри неизменяемого. Кэш урона, который
обновляется «мимо» `&self`, и первое знакомство с паникой двойного заимствования.

## Легенда

Расчёт урона героя усложнился: уровень, оружие, благословение. Пересчитывать каждый
удар — расточительно, кэшируем. Но метод удара в бою получает `&self` (никто не даёт
`&mut` посреди раунда)… и тут появляется `Cell` — коробочка, которую можно менять
даже через неизменяемую ссылку.

## Задачи

- [ ] Заведи `struct DamageCache { base: u32, level: u32, cached: Cell<Option<u32>> }`.
- [ ] Метод `fn current(&self) -> u32` с `&self`: если `cached.get()` — `Some(x)`,
      вернуть x; иначе посчитать (base + level × 2), сохранить `cached.set(Some(v))`,
      вернуть. Заметь: меняем поле через `&self` — законно, потому что `Cell`.
- [ ] Метод `fn set_level(&self, level: u32)` — тоже `&self`: меняет уровень и
      сбрасывает кэш (`cached.set(None)`). Проверь тестом: после смены уровня урон новый.
- [ ] `RefCell`-журнал: `struct Hero { ..., observations: RefCell<Vec<String>> }` и
      метод `fn note(&self, text: String)` — push в журнал через
      `self.observations.borrow_mut().push(text)`. В «осмотреться» герой замечает детали.
- [ ] Эксперимент-ловушка: в `note` после `borrow_mut()` сделай второй `borrow_mut()`
      подряд (временно) — получи панику «already borrowed». Прочитай, верни как было.
      В комментарии: чем это отличается от ошибки компиляции с `&mut`? (Подсказка:
      проверка переехала из компилятора в выполнение.)
- [ ] Ответь в комментарии: почему `Cell` подошёл для кэша (типы Copy), а `RefCell`
      нужен для `Vec<String>`?
- [ ] * Звёздочка: счётчик «сколько раз кэш пересчитан» — ещё один `Cell<u32>`
      рядом с кэшем; печатай в статистике.

## Самопроверка

- Урон меняется при смене уровня, между сменами — берётся из кэша (счётчик звёздочки
      это доказывает).
- Журнал наблюдений героя пополняется из «осмотреться» и печатается.
- Комментарии про панику RefCell и про Cell-vs-RefCell на месте.

## Подсказки

- `Cell` — для Copy-типов, без borrow: `get()`/`set()`.
- `RefCell` — для остальных: `borrow()`/`borrow_mut()`, правила заимствования
  проверяются при выполнении, нарушение = паника.
- `use std::cell::{Cell, RefCell};`
