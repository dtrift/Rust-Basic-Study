# ДЗ 34. Практика: потоки, куча, mutex, atomic

- **Урок:** 34. Практика. Потоки, куча, mutex, atomic
- **Ветка:** `hw-34-threads-practice`
- **Время:** примерно 2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-34-threads-practice`.

## Цель

Большая финальная практика по потокам: гонка искателей сокровищ. Несколько потоков
собирают золото из комнат с общей картой, идёт живое табло, в конце — победитель.

## Легенда

В подземелье объявили чемпионат: четверо искателей одновременно прочёсывают комнаты
и выносят золото. Кто соберёт больше — тот чемпион. Каждому — свой поток, карте —
мьютекс, зрителям — живое табло.

## Задачи

- [ ] Подготовь мир: раздай комнатам золото (`gold: u32` в `Room`, суммы разные).
- [ ] Общая карта: `Arc<Mutex<HashMap<String, Room>>>` — вся карта из `Game` переезжает
      под замок (достаточно карты с золотом: `Arc<Mutex<HashMap<String, u32>>>`).
- [ ] Искатели: 4 потока с именами (`move`-замыкания). Каждый в цикле: случайная комната
      (`rand`), под замком взять оттуда 1–5 золота (не больше, чем есть), прибавить себе.
- [ ] Табло: `Arc<Mutex<Vec<u64>>>` (по слоту на искателя) — после каждого взятия золота
      искатель обновляет свой слот; главный поток раз в секунду печатает табло, пока
      идут гонки.
- [ ] Финиш: гонка заканчивается, когда всё золото вынесено (карта пуста) — проверяй
      под тем же замком; главный поток делает `join` всех и объявляет чемпиона.
- [ ] Атомики: `Arc<AtomicU32>` — счётчик «взятий золота» всего; печать после финиша.
- [ ] Тест: один поток-искатель на карте из одной комнаты с 10 золота собирает ровно 10
      (запусти поток из `#[test]` и сделай `join`).
- [ ] * Звёздочка: чат болельщиков — третий поток с журнал-событиями «X взял золото
      из Y» через `mpsc::channel` (стандартный, из std::sync::mpsc), главный печатает.

## Подсказки

- Держи замок коротко: взял золото из комнаты — отпустил замок — обновил табло
  (отдельный замок). Не делай всё под одним `lock()`, иначе потоки выстроятся в очередь.
- Живое табло из главного цикла: `loop { печать; sleep 1s; если финиш — break }`,
  а `join` после него.
- Если табло мигает и мешает вводу — это нормально для этой задачи, отдельную
  «боевую» игру гонка не заменяет (можно вынести в отдельную команду «гонка»).
