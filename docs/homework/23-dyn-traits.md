# ДЗ 23. Динамический полиморфизм. dyn Trait. dyn Any

- **Урок:** 23. Обобщённое программирование. Динамический полиморфизм. dyn Trait. dyn Any
- **Ветка:** `hw-23-dyn-traits`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-23-dyn-traits`.

## Цель

Собрать комнату, где живут разные существа в одном списке `Vec<Box<dyn Creature>>`,
и понять, чем `dyn Trait` отличается от генерика и почему нужен `Box`.

## Легенда

В пещере героя ждут гоблин, скелет и летучая мышь. Разные типы — но всех надо
показать в одном списке и заставить по очереди действовать. Один список — один тип
элемента; `Box<dyn Creature>` и есть тот самый «любой, кто Creature».

## Задачи

- [ ] Заведи ещё 2–3 вида монстров (разные структуры или одна структура с разными
      наборами характеристик — как удобнее твоему коду).
- [ ] Собери зверинец: `let mut beasts: Vec<Box<dyn Creature>> = vec![...]` —
      заполни тремя существами (героя туда класть не обязательно).
- [ ] Обойди всех: печать «имя — hp/максимум — жив/мёртв» через методы трейта.
      Обрати внимание: список разных типов, а код один.
- [ ] «Ход существ»: функция `fn everyone_attacks(beasts: &mut Vec<Box<dyn Creature>>, hero: &mut Hero)` —
      каждый живой бьёт героя (метод `take_hit` героя через `Fighter`). Выведи, кто
      сколько нанёс, и сколько hp у героя осталось.
- [ ] Ответь в комментарии: почему нельзя `Vec<dyn Creature>` без `Box`?
      (Подсказка: сколько байт занимает элемент списка?)
- [ ] Примерь `&dyn` против `Box<dyn>`: функция `fn describe(c: &dyn Creature)` принимает
      ссылку — вызови её на элементе списка (`describe(beasts[0].as_ref())`), а сам
      список оставь во владении `Box`.
- [ ] * Звёздочка: `dyn Any` — приведение вниз: обход списка, и если существо —
      конкретно `Goblin` (`(beast.as_ref() as &dyn Any).downcast_ref::<Goblin>()`),
      пусть крадёт 5 золота у героя. Подсказка: для `Any` тип должен быть `'static`.

## Самопроверка

- Один `Vec` хранит существ разных типов/наборов, обход печатает всех.
- `everyone_attacks` уменьшает hp героя; погибшие существа пропускаются.
- Комментарий про `Box` и размер есть.

## Подсказки

- `Box` кладёт значение в кучу, а в списке остаётся указатель фиксированного размера —
  поэтому `Vec<Box<dyn Creature>>` работает.
- Генерик (урок 19) — свой код на каждый тип, `dyn` — один код на все типы,
  но через указатель. Это и есть «статический против динамического» полиморфизма.
- `beasts[0].as_ref()` даст `&dyn Creature` из `Box<dyn Creature>`.
