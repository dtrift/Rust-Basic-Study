# ДЗ 04. Сложные типы данных. Кортеж, структура, перечисление

- **Урок:** 4. Сложные типы данных. Кортеж, структура, перечисление
- **Ветка:** `hw-04-struct-tuple-enum`
- **Время:** примерно 1–1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-04-struct-tuple-enum`.

## Цель

Собрать разрозненные переменные героя в одну структуру, позицию хранить кортежем,
а класс героя описать перечислением.

## Легенда

Переменных у героя стало много, и их неудобно таскать по функциям по одной. Пора
упаковать героя в одну сущность — структуру. А ещё у героя появляется класс, который
может быть только одним из трёх вариантов — это работа для enum.

## Задачи

- [ ] Объяви `enum Class` с тремя вариантами на свой вкус (например, `Warrior`, `Mage`, `Rogue`).
- [ ] Объяви `struct Hero` с полями: `name` (String), `class` (Class), `hp`, `max_hp`,
      `level` (u32), `gold` (u64), `position` — кортеж `(i32, i32)`.
- [ ] В `main()` создай трёх героев разных классов с разными стартовыми характеристиками
      (например, воин — много здоровья, маг — мало здоровья, разбойник — много золота).
- [ ] Перепиши `describe_hero` из ДЗ-03: теперь она принимает один аргумент — `&Hero` —
      и печатает карточку, включая класс и позицию. Подсказка: класс переведи в строку
      через `match`.
- [ ] Напиши функцию `start_position(class: &Class) -> (i32, i32)`: разные классы
      начинают в разных местах карты. Напечатай, откуда стартует каждый герой.
- [ ] * Звёздочка: добавь кортежную структуру `Gold(pub u64)` и используй её для поля золота:
      `Gold(125)`. Достань число через `.0`.

## Самопроверка

- `cargo run` печатает карточки трёх героев с классами и разными позициями.
- Класс печатается словом (например, «Воин»), а не `Warrior` и не `Class::Warrior`.
- `describe_hero` принимает одну структуру, а не шесть аргументов.

## Подсказки

- `match hero.class { Class::Warrior => "Воин", ... }` — и это уже первый pattern matching,
  подробно будет в уроке 13.
- Создать героя: `Hero { name: String::from("Артур"), class: Class::Warrior, hp: 100, ... }`.
- Поля структуры в `println!`: `println!("{}", hero.name)`.
