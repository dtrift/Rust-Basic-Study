# ДЗ 12. Структуры и методы. Инкапсуляция

- **Урок:** 12. Структуры и методы. Инкапсуляция
- **Ветка:** `hw-12-methods`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-12-methods`.

## Цель

Перенести всю логику героя и предметов в методы: `hero.heal(20)` вместо наборов
свободных функций. Появляется конструктор и правило «изменяй героя только методами».

## Легенда

Свободные функции типа `take_damage(hero, 10)` работают, но настоящий код на Rust
выглядит как `hero.take_damage(10)`. Сегодня у героя появляются «умные» методы,
которые не дают ему вылечиться выше максимума или получить урон ниже нуля, —
и предметы становятся полноценной структурой.

## Задачи

- [ ] Перенеси функции героя в `impl Hero`: `describe(&self)`, `take_damage(&mut self, amount: u32)`,
      `heal(&mut self, amount: u32)`, `is_alive(&self) -> bool`, `gain_gold(&mut self, amount: u64)`,
      `spend_gold(&mut self, amount: u64) -> bool`.
- [ ] Инварианты внутри методов: `heal` не лечит выше `max_hp`, `take_damage` не уходит
      ниже нуля (`saturating_sub`).
- [ ] Ассоциированная функция-конструктор `Hero::new(name: String, class: Class) -> Hero`:
      стартовые характеристики по классу задаются внутри (match по классу).
      Создание героя в `main` теперь — одна строка.
- [ ] Новая структура `Item { name: String, weight: u32 }` с методами:
      `Item::new(name, weight)`, `is_heavy(&self) -> bool` (тяжёлый — больше 10).
- [ ] Инвентарь теперь `Vec<Item>`. Обнови `give_item` → метод `hero.pick_up(&mut self, item: Item)`
      и `take_last_item` → метод `hero.drop_last(&mut self) -> Item` (внутри всё тот же `pop`,
      пока с `expect`).
- [ ] Перепиши игровой цикл и `battle` на вызовы методов. Свободные функции, дублирующие
      методы, удали.
- [ ] * Звёздочка: метод `Hero::battle_cry(&self)` печатает боевой клич в зависимости от
      класса (у воина — громко, у мага — с прищуром, у разбойника — ехидно).

## Самопроверка

- `cargo run`: игра из ДЗ-09 работает, но весь доступ к полям героя идёт через методы.
- `hero.heal(999)` не поднимает hp выше `max_hp` — проверь выводом.
- `cargo test` зелёный: добавь тесты на `heal` выше максимума и `spend_gold` без денег.

## Подсказки

- Метод с `&self` вызывается на экземпляре: `hero.describe()`.
- Ассоциированная функция без `self` — на типе: `Hero::new(...)`.
- В `main` допустимо читать поля для печати (инкапсуляцию «по-настоящему» включим,
  когда появятся модули в уроке 37). Правило одно: изменять — только методами.
