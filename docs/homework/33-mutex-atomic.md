# ДЗ 33. Mutex, Atomic

- **Урок:** 33. Mutex, Atomic
- **Ветка:** `hw-33-mutex-atomic`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-33-mutex-atomic`.

## Цель

Разложить инструменты по местам: атомики для счётчиков, мьютекс для сложных данных.
Герой получает голод, а босс — двух спутников, бьющих одновременно.

## Легенда

Два события. Первое: в подземелье нечем есть — голод героя тикает в фоне, и когда он
достигает предела, удары слабеют. Второе: финальный босс так силён, что герой зовёт
двух спутников — все трое бьют одновременно, и hp босса лежит в общей мьютекс-шкатулке.

## Задачи

- [ ] Голод: `Arc<AtomicU8>` в фоне уменьшается на 1 раз в 4 секунды (не ниже 0).
      В игровом цикле читай `hunger.load(Ordering::Relaxed)`: 0 — урон героя уменьшен
      вдвое; еда из сумки (`Command::Eat`) восстанавливает до 100.
- [ ] Босс: `Arc<Mutex<Monster>>`. Проверь в комментарии: почему просто `Monster`
      нельзя, а `Arc<Mutex<...>>` можно передать трём потокам?
- [ ] Спутники: в бою с боссом запускай 2 потока, каждый делает 3 удара (пауза 0.5 сек),
      каждый удар — `boss.lock().unwrap().take_hit(dmg)` и печать «Спутник бьёт».
- [ ] Главный поток одновременно («своими силами») тоже бьёт — в цикле, пока жив босс
      или не прошло N раундов; завершение — join обоих спутников.
- [ ] Атомарный счётчик урона: `Arc<AtomicU32>` — сколько всего нанесено ударами всех
      троих; после боя печатай вклад каждого (спутники возвращают свой урон из потока —
      `join` возвращает значение замыкания!).
- [ ] Проверка на гонку: запусти игру пару раз — итоговый hp босса всегда корректен
      (никаких отрицательных/зашкаливающих значений): мьютекс гарантирует.
- [ ] * Звёздочка: сравни: заменить `Mutex<Monster>` на две AtomicU32 (hp и dmg) —
      что станет неудобно? Напиши вывод в комментарии.

## Самопроверка

- Бой с боссом: удары спутников и героя видны вперемешку, hp босса уменьшается без
      аномалий, победа засчитывается один раз.
- Голод реально ослабляет удары при 0 и лечится едой.
- После победы — таблица вклада в урон, сумма совпадает с атомарным счётчиком.

## Подсказки

- Порядок `Ordering::Relaxed` годится для счётчиков, где важна скорость, а не порядок.
- Замыкание потока может вернуть значение: `thread::spawn(move || { ...; my_damage })`,
  и `handle.join().unwrap()` отдаст его.
- `take_hit` уже есть из трейта `Fighter` — переиспользуй.
