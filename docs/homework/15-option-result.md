# ДЗ 15. Введение в систему типов. Result, Option, ()

- **Урок:** 15. Введение в систему типов. Типы стандартной библиотеки. Result, Option, ()
- **Ветка:** `hw-15-option-result`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-15-option-result`.

## Цель

Научиться главному идиому Rust: «значение, которого может не быть» (`Option`) и
«результат, который может провалиться» (`Result`). Убрать из кода заплатку `expect`.

## Легенда

До сих пор, если в сумке не было предмета, программа могла упасть с паникой — как будто
игра вырубается от удивления. Взрослые игры так не делают: они говорят «в сумке пусто»
и продолжают. Тип `Option` — это честное «может не быть», `Result` — честное «не вышло,
и вот почему».

## Задачи

- [ ] Перепиши `drop_last(&mut self) -> Item` → `drop_last(&mut self) -> Option<Item>`
      без `expect`. В игровом цикле обработай: `if let Some(item) = hero.drop_last() { ... } else { «сумка пуста» }`.
- [ ] Метод `find_item(&self, name: &str) -> Option<&Item>`: поиск по сумке обычным циклом
      (сравнивай `item.name == name`). Если нет — `None`.
- [ ] Команда `Take(name)` теперь: нашёл предмет в комнате — взял; нет — «здесь нет {name}».
      Используй `find_item` или проверку `Option`.
- [ ] Разбор чисел: добавь команду «выпить зелье N», где N — номер предмета в сумке.
      `input.parse::<usize>()` возвращает `Result<usize, ParseIntError>` — обработай:
      не число → «номер должен быть числом», число за границей → «нет такого номера».
- [ ] Разберись с `()`: функция, которая ничего не возвращает, возвращает `()`.
      Напиши в комментарии у `enter_room`: почему ей нечего возвращать?
- [ ] Убедись: в коде игры больше нет `expect` и `unwrap` (кроме тестов).
      Проверь поиском: `grep -n "unwrap\|expect" src/main.rs`.
- [ ] * Звёздочка: функция `nth_item(list: &[Item], n: Option<usize>) -> Option<&Item>` —
      если `n` — `Some(i)` и индекс в границах, вернуть предмет, иначе `None`.
      Целых два Option в одной функции!

## Самопроверка

- «Возьми меч» при отсутствии меча печатает внятное сообщение, игра продолжается.
- «Выпить зелье абракадабра» → «номер должен быть числом», игра продолжается.
- `grep -n "unwrap\|expect" src/main.rs` пуст (или только в `mod tests`).

## Подсказки

- `Option` — тот же enum: `Some(значение)` / `None`. Его можно матчить.
- `match found { Some(item) => ..., None => ... }` или короче `if let Some(item) = found { ... }`.
- `Result` — `Ok(значение)` / `Err(ошибка)`: `match n.parse::<usize>() { Ok(i) => ..., Err(_) => ... }`.
