# ДЗ 39. Макросы — декларативные и процедурные

- **Урок:** 39. Макросы - декларативные и процедурные
- **Ветка:** `hw-39-macros`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-39-macros`.

## Цель

Написать свои декларативные макросы `macro_rules!` для журнала игры и бойни монстров.
Понять, чем макрос отличается от функции, и зачем они вообще нужны.

## Легенда

Везде в коде — повторяющиеся украшательства: префиксы «🌍» и «⚔», метки времени,
отступы журнала. Функция не может принять «любое число аргументов», а макрос — может:
`log!("Гоблин повержен")`, `log!("Найдено", 3, "предмета")`. И завод монстров
сокращается до одной строки: `monster!(Goblin, 30, 5)`.

## Задачи

- [ ] Макрос `log!`: принимает 1 и больше аргументов (`($first:expr $(, $rest:expr)* $(,)?)`),
      печатает с префиксом `[журнал]` и текущим временем (`std::time::SystemTime` —
      секунды хватит). Замени минимум 3 печати в игре на `log!`.
- [ ] Макрос `monster!`: `monster!(Goblin, 30, 5)` создаёт `Monster` с именем-строкой
      («Goblin» → `String`), hp и уроном. Заведи 3+ монстров одной строкой каждый.
- [ ] Правило повторения: макрос `sum!` — `sum!(1, 2, 3, 4)` складывает любое число
      аргументов (разбор повторения `$( $x:expr ),*`). Добавь тест `assert_eq!(sum!(1,2,3), 6);`.
- [ ] Ответь в комментарии в конце файла с макросами: чем макрос отличается от функции?
      Когда происходит его «разворачивание»? Почему `log!` нельзя написать функцией?
- [ ] * Звёздочка (по-настоящему факультативная): процедурный макрос — отдельный крейт
      `macros_derive` с `derive(DebugLike)`, печатающим имя типа и полей. Если хочется
      попробовать — наставник поможет с настройкой. Не обязательно.

## Самопроверка

- `log!` работает с 1, 2 и 3 аргументами; в игре минимум 3 вызова.
- Монстры создаются макросом, объявление читается как строка таблицы.
- `cargo test` зелёный, тест `sum!` проходит.
- Комментарий-объяснение про макрос vs функция на месте.

## Подсказки

- Макросы разворачиваются ДО компиляции: компилятор видит уже готовый код.
  Поэтому им доступно «любое число аргументов».
- Начни с простого: `macro_rules! log { ($($arg:tt)*) => { println!("[журнал] {}", format!($($arg)*)) } }`
  — потом усложняй префиксом времени.
- Держи макросы в одном файле (`macros.rs`), подключи `#[macro_use] mod macros;` или
  `macro_rules` с `pub(crate)`.
