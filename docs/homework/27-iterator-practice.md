## Цель

Большая практика: экран статистики целиком на конвейерах итераторов плюс собственный
тип с реализацией `Iterator` — обход пути по комнатам.

## Легенда

У игры появляется пауза со статистикой: что собрано, что дорого, что тяжело, где герой
уже бывал. А ещё — карта пути: стартовав от текущей комнаты, можно пройти по цепочке
выходов. Цепочку комнат удобно сделать настоящим итератором — своим.

## Задачи

- [ ] Команда «статистика» (`Command::Stats`) — экран из запросов, каждый — конвейер:
      1. топ-3 предмета по весу (`iter()`, `max_by_key` в цикле или `sorted` вручную — без
         внешних крейтов: собери `Vec<&Item>`, отсортируй `sort_by_key` и возьми `take(3)`);
      2. суммарная стоимость (добавь поле `price: u32` в `Item`, если ещё нет) — `sum`;
      3. предметов дороже 100 — `filter` + `count`;
      4. средний вес — `sum` / `len` (осторожно с делением на ноль!).
- [ ] Статистика мира: сколько комнат посещено (`HashMap` из ДЗ-25 непустой? посчитай
      ключи со значением > 0), живых монстров во всём мире (`world.values()` + `filter`).
- [ ] Свой итератор пути: `struct ExitsIterator<'a> { world: &'a HashMap<String, Room>, current: Option<&'a str> }`
      с `impl Iterator for ExitsIterator`: `next()` отдаёт название текущей комнаты и
      переходит в первый её выход (упрощение: всегда первый). Пройти `for room in ExitsIterator::from(&game)`
      и напечатать «маршрут».
- [ ] Ограничь итератор: максимум 10 шагов (`take(10)`), чтобы цикл выходов не залетал
      навсегда. Объясни в комментарии, зачем `take` здесь обязателен.
- [ ] Тесты: статистика на пустой сумке (0, 0, 0 и средний вес без паники — договоримся:
      пустая сумка = вес 0); `ExitsIterator` на карте из 3 комнат останавливается.
- [ ] * Звёздочка: `filter_map` — собрать `Vec<&str>` названий комнат, где лежат предметы,
      из `world.iter()` одной цепочкой.

## Самопроверка

- Экран статистики печатает все пункты на любой сумке, включая пустую.
- Маршрут по комнатам печатается и заканчивается сам (`take(10)`).
- В новом коде нет явных `loop`/`while` для подсчётов — только конвейеры.

## Подсказки

- `impl<'a> Iterator for ExitsIterator<'a> { type Item = &'a str; fn next(&mut self) -> Option<Self::Item> { ... } }`.
- В `next()`: достань `current`, найди в `world` его первый выход, обновись, верни старое.
- Деление: `if count == 0 { 0 } else { sum / count as u32 }`.
