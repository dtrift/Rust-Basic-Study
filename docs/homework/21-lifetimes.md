# ДЗ 21. Времена жизни

- **Урок:** 21. Времена жизни
- **Ветка:** `hw-21-lifetimes`
- **Время:** примерно 1–1.5 часа (задание нарочно короткое — тема тяжёлая)

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-21-lifetimes`.

## Цель

Понять, что компилятор проверяет у ссылок, и перестать бояться `<'a>`.
Сделать ровно три вещи и хорошо их объяснить.

## Легенда

Карта игры хранит названия комнат. Экран «ты здесь» показывает название комнаты и
имя героя — обе строки живут в разных местах. Чья строка проживёт дольше — та и
определит время жизни ссылки на неё. Компилятор хочет гарантий, что пока экран
держит строку, никто её не удалит.

## Задачи

- [ ] Функция `longest_name<'a>(a: &'a str, b: &'a str) -> &'a str` — верни более длинное
      название комнаты. Вызови на двух `&str` и объясни в комментарии: что означает `'a`
      и что будет, если аргументы живут разное время (попробуй переменную, определённую
      внутри блока, — компилятор откажет; прочитай ошибку E0597).
- [ ] Структура со ссылкой `struct RoomView<'a> { room_name: &'a str, description: &'a str }`
      и функция `make_view<'a>(room: &'a Room) -> RoomView<'a>`. Создай view для комнаты
      и напечатай. Ответь в комментарии: почему у структуры появился `'a`, а раньше не было?
- [ ] Эксперимент «висячая ссылка»: напиши функцию, которая создаёт `String` внутри себя
      и пытается вернуть `&s` — получи ошибку E0515, прочитай, верни `String` вместо ссылки.
      В комментарии: почему возвращать `String` здесь правильно?
- [ ] * Звёздочка: заведи `static GAME_TITLE: &str = "Моё подземелье";` и функцию
      `title() -> &'static str`. Почему для неё не нужны аргументы-ссылки?

## Самопроверка

- `cargo run` печатает длиннейшее название, view комнаты и заголовок (звёздочка).
- В коде три комментария с ответами (`'a`, структура, E0515).
- Ни одной «подавленной» ошибки: никаких `unsafe` и хитрых обходов.

## Подсказки

- Времена жизни ничего не меняют во время работы программы — это лишь метки для
  проверки компилятором. Думай о `'a` как о ярлыке «эта ссылка живёт столько же».
- E0597 — «borrowed value does not live long enough», E0515 — «cannot return reference
  to local variable». `rustc --explain` — твой друг.
- Хорошая новость: в 90% случаев компилятор выводит времена жизни сам (elision),
  аннотации нужны структурам и функциям с несколькими ссылками.
