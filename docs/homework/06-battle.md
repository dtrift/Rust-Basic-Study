# ДЗ 06. Практика: типы, переменные, функции, ветвление, циклы

- **Урок:** 6. Практика. Типы данных. Переменные и функции. Ветвление и циклы
- **Ветка:** `hw-06-battle`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-06-battle`.

## Цель

Собрать всё пройденное в полноценный пошаговый бой со случайным уроном — первую
«настоящую» игровую механику. Заодно научиться подключать библиотеки через cargo.

## Легенда

Гоблин из ДЗ-05 был разминкой. Теперь бой становится серьёзным: раунды, случайный
урон, счётчик ходов, награда за победу. Таких боёв в игре будет много — значит,
логику нужно вынести в функции, а не держать в `main`.

## Задачи

- [ ] Подключи библиотеку случайных чисел: `cargo add rand`.
- [ ] Напиши функцию `roll_damage(base: u32) -> u32`: базовый урон плюс случайное
      число от 0 до 3 (`rand::rng().random_range(0..=3)` — если метод называется
      иначе, тебе попалась другая версия rand, загляни в подсказку).
- [ ] Напиши функцию `battle(hero_hp: u32, hero_base: u32, monster_name: &str, monster_hp: u32, monster_base: u32) -> (u32, bool)`,
      которая проводит бой раундами: в каждом раунде оба наносят урон (сначала герой),
      печатаются раунды и остатки здоровья. Функция возвращает кортеж: здоровье героя
      после боя и `true`, если победил герой. Ссылки появятся только в уроках 7–8 —
      поэтому пока передаём числа по значению и возвращаем результат.
- [ ] Используй `battle` в игровом цикле: встреча с гоблином (hp 30, базовый урон 3),
      герой (урон из `damage_per_hit(level)` из ДЗ-03).
- [ ] После победы: награда — случайное золото 10–30, печать баланса. После поражения:
      «Игра окончена» и предложение сыграть заново (внешний цикл: «сыграть ещё? да/нет»).
- [ ] * Звёздочка: критический удар — с шансом 1 к 6 урон удваивается, печатай «КРИТ!».

## Самопроверка

- `cargo run`: можно драться с гоблином несколько партий подряд, урон меняется от раунда к раунду.
- Победа приносит золото, поражение предлагает реванш, «выход» работает.
- В `main` — только игровой цикл и вызов `battle`, вся логика боя — в функции.
- `Cargo.toml` содержит `rand` в списке dependencies.

## Подсказки

- В rand 0.9: `use rand::Rng; rand::rng().random_range(0..=3)`. В более старых версиях:
  `rand::thread_rng().gen_range(0..=3)`. Посмотри, что подсказывает редактор.
- Разобрать кортеж можно так: `let (hero_hp, won) = battle(hero_hp, 8, "Гоблин", 30, 3);`.
- Играть удобнее, если каждый раунд печатается с номером и здоровьем обеих сторон.
