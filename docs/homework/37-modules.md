# ДЗ 37. Сборка. Модули

- **Урок:** 37. Сборка. Модули
- **Ветка:** `hw-37-modules`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-37-modules`.

## Цель

Разложить тысячестрочный `main.rs` по модулям: герой — отдельно, мир — отдельно,
команды — отдельно. Появляется `lib.rs`, честная инкапсуляция и тесты на месте
своего модуля.

## Легенда

Проект вырос: в одном файле герой, монстры, карта, магазин, арена, потоки.
Пора переезжать из однушки в многоквартирный дом: у каждого модуля своя комната,
на двери — табличка `pub`, и видно, кто кем пользуется.

## Задачи

- [ ] Разбей код на модули (файлы в `src/`): `hero.rs`, `monster.rs`, `world.rs` (Room,
      RoomEvent, карта), `commands.rs` (parse_command, таблица команд), `battle.rs`
      (strike, duel), `shop.rs` — по твоей фактической структуре; можно иначе, но
      осмысленно.
- [ ] `src/lib.rs` объявляет модули (`pub mod hero; ...`), `src/main.rs` — тонкий:
      создаёт `Game`, вызывает `game_loop`. Больше почти ничего.
- [ ] Инкапсуляция по-настоящему: поля `Hero` сделай приватными (без `pub`), доступ —
      только через `pub`-методы. Компилятор покажет все места, где ты лазил в поля
      напрямую — перепиши их на методы. Оцени: сколько нашлось?
- [ ] `Game` тоже в своём модуле (`game.rs`): поля приватные, наружу — методы
      (`current_room_description()`, `hero_status()` и т.п.).
- [ ] Тесты разложи по модулям: тесты героя — в `hero.rs` под `#[cfg(test)] mod tests`,
      тесты команд — в `commands.rs`, и т.д. (интеграционные — можно в `tests/`).
- [ ] `cargo build` чистый, `cargo test` зелёный, игра работает как раньше.
- [ ] * Звёздочка: `cargo doc --open` — сгенерируй документацию проекта, посмотри
      на свои модули; добавь `///`-комментарии на 3–5 публичных методов.

## Самопроверка

- В `main.rs` меньше ~30 строк.
- Попытка `game.hero.hp = 100` вне модуля героя — ошибка компиляции (приватно).
- `cargo test` зелёный, все прежние тесты живы и разложены по домам.

## Подсказки

- Обращение из модуля в модуль: `use crate::hero::Hero;` — `crate` = корень проекта.
- Структура файлов: `mod hero;` в `lib.rs` ищет файл `src/hero.rs`.
- Если поля приватны, а тестам нужен доступ — держи тесты в том же модуле:
  приватное видно внутри модуля.
