# ДЗ 13. Перечисления и pattern matching

- **Урок:** 13. Перечисления и pattern matching
- **Ветка:** `hw-13-enums-matching`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-13-enums-matching`.

## Цель

Заменить сравнение строк пользователя на честные типы: `enum Command` с данными
в вариантах и `match` по ним. Это позвоночник всей дальнейшей игры.

## Легенда

Игрок вводит «иди север», «возьми меч», «бей». Сравнивать сырые строки — хрупко:
опечатка, лишний пробел — и игра молчит. Сегодня ввод превращается в настоящую
команду — значение enum — а дальше игра сопоставляет команды с образцом и действует.

## Задачи

- [ ] Объяви `enum Direction { North, South, East, West }` и функцию
      `direction_name(dir: &Direction) -> &str` через match.
- [ ] Объяви `enum Command { Look, Go(Direction), Attack, Take(String), Quit, Unknown }`.
- [ ] Напиши парсер `parse_command(input: &str) -> Command`:
  - «осмотреться» → `Look`
  - «иди север» (и остальные стороны) → `Go(Direction)`
  - «бей» → `Attack`
  - «возьми меч» → `Take("меч")` — выдели предмет: `input.strip_prefix("возьми ")`
  - «выход» → `Quit`
  - остальное → `Unknown`
- [ ] В игровом цикле замени `match choice.as_str()` на `match parse_command(&choice)`:
  - `Look` — печать описания комнаты;
  - `Go(dir)` — печать «Ты идёшь на север» и смена позиции на ±1 по соответствующей оси;
  - `Attack` — вызов боя, если монстр жив, иначе «бить некого»;
  - `Take(name)` — положить `Item` с этим именем в сумку (вес пока фиксированный);
  - `Quit` — выход;
  - `Unknown` — «Не понимаю».
- [ ] `match` должен быть исчерпывающим: без ветки `_` там, где перечислены все варианты
      (пусть компилятор проверяет тебя).
- [ ] * Звёздочка: поддержи «север/юг/восток/запад» и «n/s/e/w» — один и тот же вариант.

## Самопроверка

- Все команды работают как раньше, но в `main` нет сравнения строк игрока напрямую.
- В `match parse_command(...)` есть образец с данными: `Command::Go(dir) => ...`,
  `Command::Take(name) => ...`.
- Опечатка в команде аккуратно печатает «Не понимаю», игра не падает.

## Подсказки

- Данные в варианте: `Command::Go(Direction::North)` — полный путь при создании.
- `input.strip_prefix("возьми ")` вернёт `Option<&str>` — пока можно `.unwrap_or("ничего")`.
- `Command` и `Direction` — тоже данные, их можно класть в переменные и передавать в функции.
