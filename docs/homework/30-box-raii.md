# ДЗ 30. Работа с кучей. Box, Arc, Rc. RAII

- **Урок:** 30. Работа с кучей. Box, Arc, Rc. RAII
- **Ветка:** `hw-30-box-raii`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-30-box-raii`.

## Цель

Встретить рекурсивный тип и решить его через `Box`; увидеть RAII — код, который
выполняется при уничтожении значения (`Drop`); заглянуть в `Rc` для раздельного владения.

## Легенда

В тайнике находят сундук. В сундуке — предмет и… ещё один сундук. Сундуки-матрёшки
могут вкладываться друг в друга сколько угодно — и вот компилятор просит `Box`,
потому что размер «бесконечного сундука» посчитать нельзя. А когда герой погибает,
по правилам RAII его эпитафия печатается сама — без явного вызова.

## Задачи

- [ ] Объяви `struct Chest { label: String, gold: u64, inner: Option<Box<Chest>> }` —
      сначала попробуй без `Box` и получи ошибку E0072, прочитай её, потом добавь `Box`
      и объясни в комментарии, что изменилось (размер стал известен: указатель).
- [ ] Функция `open_all(chest: &Chest)` — рекурсивно обходит матрёшку и печатает:
      «Сундук „большой“: 50 золота», «Сундук „средний“: 30 золота» ... Считает итог.
- [ ] Собери в игре цепочку из 3–4 сундуков (команда «открыть сундук» в комнате события
      `RoomEvent::Chest(Box<Chest>)` — новый вариант enum).
- [ ] RAII: `impl Drop for Hero` — при уничтожении героя печатается эпитафия с именем,
      золотом и числом находок. Проверь: покажи, что Drop вызывается автоматически
      (создай героя в блоке `{}` и посмотри, когда напечатается).
- [ ] * Звёздочка Rc: сделай «тайный проход»: две разные комнаты дают в одно и то же
      «укромное место» — `Rc<RefCell<Room>>` в `exits` обеих комнат. Изменения из одной
      комнаты видны из другой (положил предмет — из другого входа он виден). Почему
      `Box` не подошёл бы?

## Самопроверка

- Сундуки открываются на любую глубину без паник; итог золота посчитан верно.
- Эпитафия героя печатается без единого явного вызова — только выход из области видимости.
- Комментарий про E0072/Box на месте.

## Подсказки

- `Box` — умный указатель в кучу; размер `Box<T>` известен всегда (это адрес),
  поэтому рекурсия «через Box» законна.
- RAII = «ресурс захватывается при создании и освобождается при уничтожении».
  `Drop` — твой деструктор.
- `Rc<RefCell<...>>` — «несколько владельцев» + «внутренняя изменяемость»; подробно
  RefCell будет в уроке 35, здесь достаточно попробовать.
