# ДЗ 07. Управление ресурсами. Клонирование. Трейт Copy. Принцип владения

- **Урок:** 7. Управление ресурсами. Клонирование. Трейт Copy. Принцип владения
- **Ветка:** `hw-07-ownership`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-07-ownership`.

## Цель

Увидеть владение своими глазами: что происходит с героем, когда его отдают в функцию,
когда его клонируют и когда он «копируется» бесплатно.

## Легенда

В игре появляется старинный фонтан. Проблема в том, что герой, который попил из
фонтана в «черновой» версии кода, почему-то возвращался из функции пустым, а золото
клонов тратилось вместо золота настоящего героя. Разберёмся, кто кем владеет.

## Задачи

- [ ] Эксперимент 1 — перенос: напиши функцию `drink_from_fountain(hero: Hero) -> Hero`,
      которая увеличивает `max_hp` на 10 и возвращает героя обратно. В `main` вызови её
      и убедись, что после вызова героем можно пользоваться только через возвращённое
      значение. Ответь в комментарии: что произошло с переменной `hero` при вызове?
- [ ] Эксперимент 2 — потеря: временно убери `-> Hero` и `return` из функции. Запусти
      `cargo build`, прочитай ошибку E0382. Верни как было. В комментарии своими словами:
      о чём эта ошибка?
- [ ] Эксперимент 3 — Copy: сделай отдельную функцию `teleport(pos: (i32, i32)) -> (i32, i32)`,
      которая сдвигает позицию на (1, 0) и возвращает её. Передай туда `hero.position`
      и заметь: старую переменную `hero.position` по-прежнему можно читать (кортеж из
      `i32` копируется, ведь `i32` — Copy). Ответь в комментарии: почему с `Hero` так
      нельзя, а с кортежем координат — можно?
- [ ] Эксперимент 4 — clone: в `main` создай «героя-двойника» через `hero.clone()`
      (подсказка ниже). Отдай двойника в функцию `sacrifice(hero: Hero)`, которая
      сжигает 50 золота. Напечатай золото обоих после вызова: у кого убыло?
      Ответь в комментарии.
- [ ] * Звёздочка: проверь через `std::mem::size_of::<Hero>()` и вычисление: сколько
      байт «переписывается» при передаче героя в функцию? А при передаче кортежа?

## Самопроверка

- `cargo run` печатает результаты всех экспериментов.
- В коде 4 комментария с ответами (перенос, E0382, Copy, clone).
- Фонтан работает: герой получает +10 к максимуму здоровья через возвращённое значение.

## Подсказки

- Для `hero.clone()` добавь `#[derive(Clone)]` над `struct Hero` — об этом подробнее
  будет позже, пока просто скопируй строку.
- E0382 — «value moved». `rustc --explain E0382` объяснит подробнее.
- Copy бесплатно «копируется» только для простых типов: числа, bool, char, кортежи из них.
