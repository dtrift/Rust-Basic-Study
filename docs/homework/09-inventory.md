# ДЗ 09. Практика: владение и заимствование

- **Урок:** 9. Практика. Владение и заимствование
- **Ветка:** `hw-09-inventory`
- **Время:** примерно 2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-09-inventory`.

## Цель

Дать герою инвентарь и провести предметы через все формы владения: создание,
передачу, возврат, обмен. И написать первые автоматические тесты.

## Легенда

Герой находит вещи — но пока их некуда класть. Сегодня у героя появляется сумка
(`Vec<String>`), торговец, готовый менять вещи, и сундук, из которого вещи можно
забрать в единственном экземпляре. Предмет, который забрали из сундука, в сундуке
больше не лежит — за этим и проследит владение.

## Задачи

- [ ] Добавь герою поле `inventory: Vec<String>` (начни с пустого: `Vec::new()`).
- [ ] Функция `give_item(hero: &mut Hero, item: String)` — кладёт предмет в инвентарь.
      Подсказка: `hero.inventory.push(item)`.
- [ ] Функция `take_last_item(hero: &mut Hero) -> String` — забирает последний предмет
      из сумки и возвращает его владелецу вызывающего кода:
      `hero.inventory.pop().expect("сумка пуста")`. Вызов с `expect` — временный,
      перепишем его по-взрослому в ДЗ-15. В `main` сразу отдай взятый предмет второму
      герою: `give_item(&mut hero2, item)`. Комментарий: кто владел предметом на каждом шаге?
- [ ] Функция `transfer_gold(from: &mut Hero, to: &mut Hero, amount: u64) -> bool`:
      если у `from` хватает золота — переводит и возвращает `true`, иначе `false`.
- [ ] Напиши первые тесты внизу `main.rs`:

  ```rust
  #[cfg(test)]
  mod tests {
      use super::*;

      #[test]
      fn transfer_moves_gold() { /* переведи 50 и проверь балансы */ }

      #[test]
      fn transfer_refuses_when_poor() { /* переведи больше, чем есть — вернулось false */ }
  }
  ```

- [ ] Запусти `cargo test` — оба теста зелёные. Добавь тест на инвентарь: дали предмет,
      забрали — в сумке пусто.
- [ ] * Звёздочка: `trade(a: &mut Hero, b: &mut Hero)` — герои обмениваются последними
      предметами из сумок (два `pop` и два `push`, или `swap` последних элементов).

## Самопроверка

- `cargo run`: можно положить предметы, забрать, передать другому герою; золото переводится.
- `cargo test` — 3 зелёных теста.
- В коде нет `clone()` для предметов: они честно переезжают из владельца во владельца.

## Подсказки

- `Vec::pop()` возвращает «может быть, предмет» — пока используем `.expect("сумка пуста")`
  как временную заплатку, в уроке 15 узнаем правильный способ.
- Тестовая функция начинается с `#[test]`, внутри — обычный код плюс макрос
  `assert_eq!(левое, правое);`.
- Создать героя-помощника для тестов можно той же структурой `Hero { ... }`.
