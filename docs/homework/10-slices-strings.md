# ДЗ 10. Коллекции. Слайсы, массивы, строки

- **Урок:** 10. Коллекции. Слайсы, массивы, строки
- **Ветка:** `hw-10-slices-strings`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-10-slices-strings`.

## Цель

Дать миру первую карту из массива комнат и разобраться со строками: сборка,
срезы и коварные границы UTF-8.

## Легенда

Мир игры — это комнаты. Пока их четыре, и их описания лежат в массиве. Игрок ходит
по номерам комнат, а игра собирает описание комнаты из частей: название, атмосфера,
кто в ней. И где-то в этом коде спрятан срез, который упадёт на русском тексте —
найди и обезвредь.

## Задачи

- [ ] Заведи массив описаний комнат: `const ROOMS: [&str; 4] = ["Вход", "Коридор", "Зал", "Тайник"];`
      (названия — из твоего сеттинга).
- [ ] Функция `describe_room(rooms: &[&str], index: usize)`: печатает «Комната 2: Коридор».
      Если индекс за границей — печатай «Куда-то не туда» (проверь `index < rooms.len()`).
- [ ] Функция `full_description(name: &str, atmosphere: &str, hero_name: &str) -> String`:
      собери строку вида «Коридор. Тут холодно. Артур оглядывается по сторонам.»
      через `format!` или `push_str`.
- [ ] Функция `first_words(text: &str, count: usize) -> &str` — первые `count` слов строки
      (по пробелам, для простоты считай, что пробелы есть). Верни срез.
- [ ] Эксперимент UTF-8: напиши функцию `first_two_chars(s: &str) -> &str` с срезом
      `&s[..2]`. Вызови на английском слове — работает. Вызови на русском — программа
      упадёт с паникой. Объясни в комментарии, почему. Почини: пусть функция возвращает
      `String` и собирает первые два символа через `s.chars().take(2).collect()`.
- [ ] Функция `show_inventory(items: &[String])` — печатает сумку через цикл по срезу.
      Вызови её на `&hero.inventory` — вот и первый слайс коллекции.
- [ ] * Звёздочка: `longest_room_name(rooms: &[&str]) -> &str` — имя самой длинной
      комнаты (без итераторов, обычным циклом со счётчиком максимума).

## Самопроверка

- `cargo run` печатает все 4 комнаты, полное описание и первые слова какой-нибудь строки.
- Паника на русском тексте объяснена в комментарии и больше не случается.
- Сумка героя печатается функцией, которая принимает срез.

## Подсказки

- Строка в Rust — байты UTF-8: русская буква занимает 2 байта, эмодзи — 4.
  Срез обязан попадать на границу символа.
- `&s[..2]` — срез «от начала до 2-го байта», а не символа!
- `format!("{}. {}.", name, atmosphere)` — самый читаемый способ собрать строку.
