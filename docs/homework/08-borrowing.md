# ДЗ 08. Владение. Ссылки и заимствование

- **Урок:** 8. Владение. Ссылки и заимствование
- **Ветка:** `hw-08-borrowing`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-08-borrowing`.

## Цель

Перестать таскать героя по значению: взять данные взаймы через `&` и `&mut`.
Это самый важный навык Rust — дальше он будет в каждой строчке.

## Легенда

Фонтан из ДЗ-07 работал, но неудобно: чтобы герой попил, его приходилось «отдавать
в залог» и забирать обратно. Настоящие герои так не купаются. Перепишем игру так,
чтобы функции одалживают героя, меняют его и отдают — без переносов туда-сюда.

## Задачи

- [ ] Перепиши `describe_hero(hero: &Hero)` — теперь берёт ссылку, ничего не возвращает.
- [ ] Перепиши `drink_from_fountain(hero: &mut Hero)` — увеличивает `max_hp` и `hp` на 10,
      ничего не возвращает. В `main`: `drink_from_fountain(&mut hero);`.
- [ ] Добавь `take_damage(hero: &mut Hero, amount: u32)` — уменьшает hp, но не ниже нуля
      (усечение: `hero.hp = hero.hp.saturating_sub(amount)`).
- [ ] Перепиши `battle` из ДЗ-06: теперь сигнатура
      `battle(hero: &mut Hero, monster_name: &str, monster_hp: &mut u32, monster_base: u32) -> bool` —
      меняет героя на месте, урон монстру — через `&mut u32`, возвращает `true` при победе героя.
- [ ] Убери из кода все `clone()` и передачи героя по значению, которые остались от ДЗ-07
      (эксперименты можно удалить или оставить в комментариях).
- [ ] Эксперимент «запретное заклинание»: попробуй в одной функции сделать два изменяемых
      заимствования (`let a = &mut hero; let b = &mut hero;`), собери, прочитай ошибку
      E0499, верни обратно. Ответь в комментарии: почему Rust это запрещает?
- [ ] * Звёздочка: функция `swap_gold(a: &mut Hero, b: &mut Hero)` обменивает золото двух
      героев местами через `std::mem::swap`. Почему здесь два `&mut` разрешены?

## Самопроверка

- Игра работает как в ДЗ-06, но в коде нет `clone()` и нет передач `Hero` по значению.
- `cargo build` чистый (эксперимент E0499 закомментирован или убран).
- В коде есть комментарий-ответ, почему два `&mut` на одного героя запрещены.

## Подсказки

- Правило: много `&` ИЛИ ровно один `&mut` в каждый момент времени.
- В `battle` герой и монстр — разные переменные, так что `&mut hero` и `&mut monster_hp`
  не конфликтуют.
- В `swap_gold` `a` и `b` — ссылки на разных героев, компилятор это видит.
