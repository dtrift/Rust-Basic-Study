- **Урок:** 14. Практика. Структуры и методы. Перечисления и pattern matching
- **Ветка:** `hw-14-room-events`
- **Время:** примерно 2 часа

## Цель

Собрать из всего пройденного играбельную игру: комнаты с разными событиями,
перемещение по миру, предметы, бои. До этого дня — прототип, после — игра.

## Легенда

Мир перестаёт быть одной комнатой. Теперь это карта: в каждой комнате что-то случается —
пусто, монстр, находка или ловушка. Что именно — описано типом `RoomEvent`, и match
разбирает все случаи без пропусков. Именно так проектируют игровые движки.

## Задачи

- [ ] `struct Monster { name: String, hp: u32, base_damage: u32 }` с методом
      `Monster::new(name, hp, base_damage)` и `is_alive(&self)`.
- [ ] `enum RoomEvent { Nothing, Monster(Monster), Item(Item), Trap { damage: u32 } }` —
      обрати внимание: два варианта несут данные разных типов.
- [ ] `struct Room { name: String, description: String, event: RoomEvent }` и функция
      `enter_room(hero: &mut Hero, room: &mut Room)`, которая match-ит по событию:
  - `Nothing` — «Тихо и пусто»;
  - `Monster(m)` — бой (твой `battle`), при победе событие комнаты меняется на `Nothing`
    (создай новый `RoomEvent::Nothing`);
  - `Item(item)` — герой подбирает предмет, событие тоже «затирается»;
  - `Trap { damage }` — герой получает урон (в фигурных скобках — именованное поле варианта).
- [ ] Мир: `Vec<Room>` из 4–6 комнат с разными событиями. Позиция героя `(i32, i32)`
      пока просто меняется, а комната выбирается по индексу: вход = 0, и т.д.
- [ ] Соедини: игровой цикл из ДЗ-13, но «иди» теперь вызывает `enter_room`.
- [ ] Добавь команду «сумка» → `Command::Inventory` в parse и match: печатает предметы.
- [ ] * Звёздочка: после победы над монстром комната получает `RoomEvent::Item`
      с трофеем (не hardcoded название — собери из имени монстра: «рог {имя}»).

## Самопроверка

- Можно пройти карту из конца в конец, собрать предметы, победить монстров, наступить на ловушку.
- Повторный вход в комнату, где монстр уже побеждён, — «Тихо и пусто» (событие затёрлось).
- В `enter_room` — один match по `RoomEvent`, во всех ветках действия осмысленные.
- `cargo test` зелёный (тесты из прошлых ДЗ не сломались).

## Подсказки

- «Затереть» событие: `room.event = RoomEvent::Nothing;` — старое значение уничтожится само.
- `match &mut room.event { RoomEvent::Monster(m) => { ... } ... }` — так можно менять
  монстра прямо внутри матча.
- Проверь себя: убери одну ветку из match — компилятор должен закричать. Верни обратно.
