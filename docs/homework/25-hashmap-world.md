# ДЗ 25. Коллекции. Big O нотация. Хэш-мэп и вектор

- **Урок:** 25. Коллекции. Big O нотация. Хэш-мэп и вектор
- **Ветка:** `hw-25-hashmap-world`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-25-hashmap-world`.

## Цель

Перевернуть мир игры в `HashMap`: комнаты по имени, а не по индексу. И научиться
отвечать на вопрос «почему эта коллекция, а не та» на языке Big O.

## Легенда

Мир растёт: комнат станет десятки и сотни, ходить придётся по именам («иди в кухню»,
«иди в тайник»). Искать комнату перебором всего списка — медленно; HashMap находит
мгновенно. Плюс у мира появляется владелец: структура `Game`, которая держит всё.

## Задачи

- [ ] `struct Game { hero: Hero, world: HashMap<String, Room>, current_room: String }`.
- [ ] Перенеси комнаты в `HashMap<String, Room>` (ключ — название комнаты).
      Ссылки между комнатами: `Room` получает поле `exits: Vec<String>` — названия
      соседних комнат.
- [ ] Команда «иди X»: если в `exits` текущей комнаты есть X и в мире есть такая комната —
      переход и `enter_room`; если нет — «отсюда туда не пройти». Поиск комнаты —
      `world.get(&name)` за O(1).
- [ ] «осмотреться» печатает комнату и доступные выходы.
- [ ] Ответь письменно в `docs/answers/25-bigo.md` (своими словами, по 1–2 предложения):
      1. Почему поиск в `HashMap` — O(1), а в `Vec` по значению — O(n)?
      2. Почему `Vec` всё равно используют: какие операции у него быстрые?
      3. Что такое хэш-коллизия (не гуглить дословно — объясни по смыслу из урока)?
      4. `world.get(&name)` вернул `None` — какие две причины могли быть в нашей игре?
- [ ] * Звёздочка: счётчик посещений комнат `HashMap<String, u32>` в `Game`:
      каждая комната помнит, сколько раз герой в неё заходил. «осмотреться» показывает.

## Самопроверка

- Ходить можно только по связанным комнатам; несуществующая — «не пройти», а не паника.
- В `Game` лежит весь мир, в `main` — только создание и запуск.
- Файл `docs/answers/25-bigo.md` отвечает на 4 вопроса.

## Подсказки

- `HashMap::new()` и `map.insert("кухня".to_string(), room)`.
- `world.get(&current)` — `Option<&Room>`; выходы — `room.exits.contains(&target)`.
- `use std::collections::HashMap;` — не забудь импорт.
