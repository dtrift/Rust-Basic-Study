# ДЗ 01. Знакомство с Rust. Подготовка к обучению

- **Урок:** 1. Знакомство с Rust. Подготовка к обучению
- **Ветка:** `hw-01-setup`
- **Время:** примерно 1 час

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-01-setup`.
> Как сдавать — [docs/git-guide.md](../git-guide.md).

## Цель

Поставить Rust, запустить проект, выбрать тему своей будущей игры и сдать первое
задание через Pull Request — так же, как будешь сдавать все остальные.

## Легенда

Следующие месяцы ты будешь делать свою собственную текстовую игру. Сегодня она
появляется на свет: ты выбираешь ей имя, мир и персонажей. Это может быть подземелье
с драконами, космическая станция, город зомби, школа магии — что угодно. Технически
все задания будут одинаковы, выбирай то, что интересно именно тебе.

## Задачи

- [ ] Установи Rust по инструкции с сайта <https://rustup.rs> (команда `rustup` должна работать).
- [ ] Проверь: `cargo --version` и `rustc --version` печатают версии.
- [ ] Запусти игру: `cargo run`. Должно напечататься приветствие.
- [ ] Придумай игру: название, мир, кто герой, кто враги, какие предметы.
- [ ] Впиши название игры в `src/main.rs` вместо `ТВОЁ НАЗВАНИЕ` (латиницей или кириллицей — как хочешь).
- [ ] Опиши свою игру в `README.md`: название, 3–5 предложений про мир и героя, что планируется.
- [ ] * Звёздочка: придумай и опиши в README трёх монстров и три предмета для своей игры.

## Самопроверка

- `cargo run` печатает приветствие с названием твоей игры.
- В README есть название и описание мира.
- PR открыт из ветки `hw-01-setup`, шаблон заполнен, чек CI зелёный.

## Подсказки

- Если `cargo` «не найден» после установки — закрой и открой терминал заново.
- Название игры в `Cargo.toml` трогать не обязательно, но если очень хочешь — оно пишется
  латиницей без пробелов (например, `dungeon-of-doom`).
- Коммить маленькими шагами: «поставил rust», «написал README» — так привычнее быстрее.
