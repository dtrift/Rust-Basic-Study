# ДЗ 18. Практика: работа с Result, Option

- **Урок:** 18. Практика. Работа с Result, Option
- **Ветка:** `hw-18-error-practice`
- **Время:** примерно 2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-18-error-practice`.

## Цель

Отработать комбинаторы `map`, `and_then`, `map_err`, `unwrap_or`, `unwrap_or_else`
на реальных игровых сценариях и закрепить правило «без паник в игровом коде».

## Легенда

Деревенский магазин открывается в игре: покупка, продажа, проверка наличия —
целая цепочка «может не быть»: товара нет, золота не хватает, сумка переполнена.
Каждый шаг честно проходит через Option/Result, и никто не паникует.

## Задачи

- [ ] `shop_buy(hero: &mut Hero, item: Item, price: u64) -> Result<(), String>`:
      не хватает золота → `Err("Нужно ещё N золота")`, сумка полна (лимит 10) →
      `Err("Сумка полна")`, иначе покупка. Ошибки пока строками — своего enum-а ошибок
      хватает на разбор команд.
- [ ] `find_item` из ДЗ-15 перепиши через цепочку: `hero.inventory.iter().find(|i| i.name == name)`
      вернёт `Option<&Item>` — а тебе нужен `Option<usize>` (индекс)? Используй
      `position` вместо `find`. Сравни: чем отличаются?
- [ ] Продажа: `sell_item(hero: &mut Hero, name: &str) -> u64` — если предмет есть,
      продай за половину веса × уровень героя; если нет — верни 0. Используй
      `if let` / `unwrap_or`.
- [ ] Перепиши три места в игровом цикле на комбинаторы (без вложенных match):
  - печать веса найденного предмета: `find_item(...).map(|i| i.weight)` — «вес: 7» или «не нашлось»;
  - покупка через `shop_buy(...)` и `unwrap_or_else(|e| e)` для сообщения;
  - номер аптечки: `parse` → `and_then` → `nth_item` одной цепочкой.
- [ ] Финальная проверка: `grep -n "unwrap\|expect\|panic!" src/main.rs` — пусто вне тестов.
- [ ] Тесты: `shop_buy` без денег → Err с текстом «Нужно ещё»; `sell_item` несуществующего → 0;
      цепочка аптечки с неверным номером → вежливое сообщение.
- [ ] * Звёздочка: сделай так, чтобы максимальный размер сумки зависел от класса героя.

## Самопроверка

- Магазин работает: купить, продать, попытка купить без денег, продажа несуществующего.
- `grep` из задачи 5 чист.
- `cargo test` зелёный, минимум 5 тестов суммарно.

## Подсказки

- `position(|x| условие)` — как `find`, но возвращает номер элемента (`Option<usize>`).
- `and_then` соединяет два шага, каждый из которых может вернуть `None`/`Err`.
- Возвращать `Result<(), String>` для простых случаев — нормально; свои типы ошибок
  оставим для следующего уровня.
