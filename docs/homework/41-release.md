# ДЗ 41. Финал: разбор приложения. Релиз v1.0

- **Урок:** 41. Пример — разбор приложения на Rust
- **Ветка:** `hw-41-release`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-41-release`.

## Цель

Выпустить игру v1.0.0: чистый код, документация, зелёный CI, тег и GitHub Release.
Курс пройден — проект должен выглядеть так, будто его автор профессионал.

## Легенда

Финальный уровень — не про монстров, а про ремесло. Настоящие проекты встречают
по README: скриншот, как собрать, как играть. Ты прошёл путь от «Привет, мир» до
асинхронного подземелья — зафиксируй это как релиз.

## Задачи

- [ ] Чистота: `cargo clippy` — почини все предупреждения (`cargo clippy --fix` поможет).
      Запусти `cargo fmt`. Ветки CI все зелёные.
- [ ] README финальный: название и сеттинг, скриншот-«сессия» (скопируй типичный запуск
      из терминала в блок кода — этого достаточно), разделы «Как собрать» (`cargo run --release`),
      «Как играть» (список команд из твоей таблицы команд), «Что внутри» (модули и темы
      курса, которые ты применил).
- [ ] Ретроспектива в конце README: какие три темы были самыми трудными и почему;
      что бы ты сказал себе на уроке 1. Честно и своими словами — это раздел для тебя.
- [ ] Версия: `version = "1.0.0"` в `Cargo.toml`.
- [ ] Тег: `git tag -a v1.0.0 -m "Релиз игры после курса Rust Basic"` на merge-коммите
      твоей ветки (после merge), затем `git push origin v1.0.0`.
- [ ] GitHub Release: Releases → Draft a new release → выбери тег `v1.0.0`, название —
      имя игры + версия, описание — пару абзацев из README.
- [ ] * Звёздочка: CHANGELOG.md — 5–7 главных вех проекта списком («v0.1 — карточка
      героя», ...) по мотивам истории коммитов (`git log --oneline`).

## Самопроверка

- `cargo clippy` молчит, `cargo test` зелёный, `cargo run --release` запускает игру.
- README показывает незнакомцу, как играть, без твоих объяснений.
- На странице репозитория есть Release v1.0.0 с тегом.
- Ретроспектива написана честно.

## Подсказки

- Скриншот-сессия: запусти игру, проиграй пару ходов, выдели текст в терминале,
  вставь в ```-блок README. Эмодзи «🌍» смотрятся отлично.
- Если clippy ругается на старый код из ранних ДЗ — это нормально: починки обычно
  копеечные (`.len() == 0` → `is_empty()` и т.п.).
- Тег ставится на commit в main ПОСЛЕ merge — тогда он не «уедет» при rebase.
