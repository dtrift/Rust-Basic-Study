# ДЗ 22. Обобщённое программирование. Наследование (трейты)

- **Урок:** 22. Обобщённое программирование. Наследование
- **Ветка:** `hw-22-traits`
- **Время:** примерно 1.5–2 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-22-traits`.

## Цель

Ввести общий язык для всего живого в игре: трейт `Creature`, который умеют и герой,
и монстры; и трейт-наследник `Fighter` с боевым поведением и методом по умолчанию.

## Легенда

В мире игры нет «героя» и «монстров» — есть существа. У всех есть имя, здоровье,
и все живы, пока hp больше нуля. Это общее поведение — работа трейта с default-методом.
А драться умеют не все: драться — отдельный трейт-наследник.

## Задачи

- [ ] Трейт `trait Creature { fn name(&self) -> &str; fn hp(&self) -> u32; fn max_hp(&self) -> u32; }`
      и метод по умолчанию `fn is_alive(&self) -> bool { self.hp() > 0 }`.
- [ ] Реализуй `Creature` для `Hero` и `Monster` (поля уже есть). Проверь: `is_alive`
      нигде не пишется дважды — он достался обоим от трейта.
- [ ] Трейт-наследник `trait Fighter: Creature { fn attack_power(&self) -> u32; fn take_hit(&mut self, damage: u32); }`.
      Реализуй для `Hero` и `Monster`.
- [ ] Переопредели `is_alive` у монстра-нежити: она жива, пока hp > 0 ИЛИ пока не
      прочитано заклинание (добавь поле `blessed: bool` — нежить считается мёртвой,
      если `blessed && hp == 0`). Урок: default-метод можно переопределить.
- [ ] Функция `strike(attacker: &mut impl Fighter, defender: &mut impl Fighter)`:
      урон по `attack_power`, у защищающегося `take_hit`, печать «X бьёт Y на N».
      Вызови герой→монстр и монстр→герой одной и той же функцией.
- [ ] Переведи бой (`battle`) на `impl Fighter` — теперь он умеет сталкивать любых бойцов.
- [ ] * Звёздочка: трейт `Descriptive { fn short(&self) -> String; }` с реализацией
      для `Hero`, `Monster` и `Item` — и функция `fn show_all(things: &[Box<dyn Descriptive>])`
      (мостик к уроку 23).

## Самопроверка

- Одна функция `strike` работает и для героя, и для монстра в обе стороны.
- Нежить не умирает от урона, пока не `blessed` — есть тест на это.
- `cargo test` зелёный; добавь тест: существо с hp=0 не `is_alive`.

## Подсказки

- `impl Fighter` в аргументе — то же, что обобщённый параметр `T: Fighter`, только короче.
- Наследование трейтов: `trait Fighter: Creature` — «чтобы драться, нужно быть существом».
- В Rust нет наследования структур: только композиция + трейты. Это проще, чем в Java/C++.
