# ДЗ 31. Потоки. Создание потоков. Send + Sync

- **Урок:** 31. Потоки. Создание потоков. Send + Sync
- **Ветка:** `hw-31-threads`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-31-threads`.

## Цель

Запустить первый фоновый поток — мир начинает жить сам: пока игрок думает,
в подземелье что-то происходит. Научиться останавливать поток и понимать,
что ему можно передать, а что нельзя.

## Легенда

Игра оживает: в глубине подземелья слышны шаги, где-то капает вода, сквозняк
гонит листья по коридорам. Всё это — фоновый поток, который раз в несколько секунд
печатает атмосферное сообщение, пока игрок читает свой ход.

## Задачи

- [ ] Заведи сообщения атмосферы: массив из 5–7 строк («Где-то капает вода», ...).
- [ ] Запусти поток `std::thread::spawn` с циклом: раз в 3 секунды печатать следующее
      сообщение (`thread::sleep`), цикл бесконечный, пока флаг `running` — `true`.
      Флаг сделай `Arc<AtomicBool>` и поделись между потоками (клонировав `Arc`).
- [ ] При выходе из игры («выход» или смерть героя): ставь `running.store(false)` и
      дожидайся поток (`handle.join()`), чтобы программа не закончилась раньше эпилога.
- [ ] Эксперимент-вопрос (в комментарии): почему в поток нельзя просто передать `&mut Game`?
      Попробуй — прочитай ошибку про lifetime/Send. Своими словами: чего боится компилятор?
- [ ] Эксперимент: передай в поток владение — `move` замыкание с собственным
      `Vec<String>` сообщений (клонированных заранее) и `Arc`-флагом. Так работает
      передача данных через владение.
- [ ] * Звёздочка: два потока — «атмосфера» и «шаги где-то рядом» с разными интервалами
      (3 сек / 7 сек); оба останавливаются по одному флагу.

## Самопроверка

- Во время хода игрока (введи паузу — подожди) появляются атмосферные сообщения.
- После «выход» программа завершается сама и без «зависших» потоков (join сработал):
      проверь, что терминал вернулся к приглашению.
- Комментарий про `&mut Game` в потоке на месте.

## Подсказки

- `let flag = Arc::new(AtomicBool::new(true)); let flag2 = Arc::clone(&flag);` —
  у флага два владельца, оба потока видят одно и то же значение.
- `use std::sync::atomic::{AtomicBool, Ordering};` и `flag.load(Ordering::Relaxed)`.
- `spawn` возвращает `JoinHandle`, `.join()` ждёт завершения потока.
