# ДЗ 03. Типы данных. Переменные и функции

- **Урок:** 3. Типы данных. Переменные и функции
- **Ветка:** `hw-03-variables-functions`
- **Время:** примерно 1–1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-03-variables-functions`.

## Цель

Создать героя из переменных правильных типов и научиться выносить повторяющиеся
вычисления в функции.

## Легенда

Игра начинается с героя. Пока он не структура (структуры будут в уроке 4) — просто
набор переменных: имя, класс, здоровье, уровень, золото. Игра встречает игрока
карточкой героя — как заставка в начале приключения.

## Задачи

- [ ] Опиши героя переменными в `main()`: имя (`&str`), здоровье `hp` и максимальное
      здоровье `max_hp` (`u32`), уровень `level` (`u32`), золото `gold` (`u64`).
- [ ] Заведи константы: `const MAX_LEVEL: u32 = 20;` и минимум здоровья `const MIN_HP: u32 = 0;`.
- [ ] Напиши функцию `describe_hero(...)`, которая принимает данные героя и печатает
      красивую карточку примерно так:

  ```text
  === ГЕРОЙ ===
  Имя:     Артур
  Здоровье: 90/100
  Уровень:  3
  Золото:   125
  ```

- [ ] Напиши функцию `damage_per_hit(level: u32) -> u32`, которая возвращает урон героя:
      базовый удар 5 + уровень × 2. Проверь для уровней 1, 3, 10 — напечатай результаты.
- [ ] Напиши функцию `heal_cost(level: u32) -> u64`: лечение стоит 10 золота за уровень.
      Посчитай, сколько стоит лечение героя 5-го уровня, и напечатай.
- [ ] * Звёздочка: сделай переменную `is_alive` типа `bool` через сравнение `hp > MIN_HP`
      и покажи в карточке строку «Жив» или «Пал» (подсказка: `if` в `println!` — можно
      напечатать `"Жив"` или `"Пал"` обычным `if`/`else`).

## Самопроверка

- `cargo run` печатает карточку героя и результаты проверки функций (урон для 1/3/10, стоимость лечения).
- Карточка выглядит аккуратно: колонки выровнены.
- Формулы в функциях, а не в `println!` — в `main` только вызовы.

## Подсказки

- В `println!` можно выравнивать: `println!("Имя: {:10}", name)` — попробуй.
- Константы объявляются вне функций, большими буквами.
- Имя героя типа `&str` (строковый литерал) — просто `"Артур"` в кавычках.
