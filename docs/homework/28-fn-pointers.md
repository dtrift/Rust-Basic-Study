# ДЗ 28. Функции. Типы функций. Лямбда-функции

- **Урок:** 28. Функции. Типы функций. Лямбда-функции
- **Ветка:** `hw-28-fn-pointers`
- **Время:** примерно 1.5 часа

> Перед стартом: `git switch main`, `git pull`, `git switch -c hw-28-fn-pointers`.

## Цель

Убрать гигантский `match` диспетчеризации команд: таблица «строка → функция».
Указатели на функции `fn` и замыкания в `Box<dyn Fn>` — когда чего хватает.

## Легенда

Матч на 50 строк в игровом цикле — это список команд, зашитый в код. Настоящие
движки держат таблицу: имя команды → функция, которая её выполняет. Добавил команду —
добавил строчку в таблицу, и ничего больше.

## Задачи

- [ ] Каждая команда — отдельная функция с одинаковой сигнатурой:
      `fn cmd_look(game: &mut Game)`, `fn cmd_inventory(game: &mut Game)` и т.д.
      (пока без Result: пусть печатают ошибки сами).
- [ ] Таблица: `let commands: HashMap<&str, fn(&mut Game)> = ...` — заполни именами
      команд из `parse_command` («осмотреться», «сумка», «статистика», «выход» ...).
- [ ] Диспетчер: по введённой строке `commands.get(&input.as_str())` → вызов указателя
      (`handler(game)`). Нет такой — «Не знаю команду». Матч-гигант из цикла удали.
- [ ] Напечатай «справку» — все команды таблицы (`commands.keys()`), по команде «помощь».
- [ ] Эксперимент-сравнение в комментарии: чем `fn(&mut Game)` (указатель на функцию)
      отличается от `Box<dyn Fn(&mut Game)>` (замыкание в куче)? Когда компилятор
      предлагает второе? (Попробуй положить в таблицу замыкание `|g| g.hero.hp = 100`
      и посмотри на ошибку типов.)
- [ ] * Звёздочка: команда «выпить зелье N» не влезает в таблицу (нужен аргумент N) —
      заведи для команд с аргументами отдельную таблицу
      `HashMap<&str, Box<dyn Fn(&mut Game, &str)>>`, где `&str` — остаток строки.
      `Box::new(|g, rest| ...)`.

## Самопроверка

- «помощь» печатает список всех команд из таблицы.
- Добавление новой команды = новая функция + одна строка в таблице (проверь, добавив
      бесполезную команду «прыгнуть»).
- Комментарий-сравнение `fn` и `Box<dyn Fn>` на месте.

## Подсказки

- Тип-указатель пишется маленькими буквами: `fn(&mut Game)` — это тип, значение
  которого — имя функции.
- Таблица живёт в `game_loop`, создавай её перед циклом один раз.
- Ошибка про «expected fn pointer, found closure» — она и есть ответ на эксперимент.
