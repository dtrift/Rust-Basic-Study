## Моя игра: «Experiment Derailed»

Будущее, человечество вымирает. Герой остаётся один, убивает тварей,
ищет выживших. Встречает Эла - такого же выжившего.

Герой узнаёт: Эл - правительственный эксперимент, вышедший из-под
контроля. Именно он уничтожил всё живое, но сам об этом не знает.

Три концовки:
- Хорошая: рассказываем Элу правду, ритуал, Эл жив, человечество вернулось.
- Средняя: скрываем правду, Эл узнаёт сам, ярость, ритуал, Эл погибает, человечество вернулось.
- Плохая: Эл узнаёт правду во время ссоры, уничтожает всё - героя, себя, Землю.
