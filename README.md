# Твоя игра на Rust

Это репозиторий текстовой игры, которая растёт вместе с курсом
«Rust Basic». Каждое домашнее задание — новый шаг в развитии игры:
от карточки героя до полноценного мира с картой, боями и фоновыми событиями.

## Быстрый старт

```bash
cargo run
```

## Как устроены домашние задания

- Все задания лежат в [docs/homework/](docs/homework/README.md) — там же таблица прогресса.
- Номер задания совпадает с номером урока. Q&A-уроки (11, 20, 29, 36, 42) без заданий.
- Каждое задание делается в отдельной ветке и сдаётся через Pull Request.

## Как сдать задание (коротко)

1. Обнови `main`: `git switch main && git pull`.
2. Создай ветку: `git switch -c hw-NN-slug` (имя ветки указано в задании).
3. Делай задание, коммить маленькими шагами.
4. Запусти `cargo build`, `cargo test` (если есть тесты) и `cargo fmt`.
5. Запушь ветку и открой Pull Request в `main` по шаблону.
6. Дождись ревью, ответь на комментарии, дождись merge.

Подробно — в [docs/git-guide.md](docs/git-guide.md).
